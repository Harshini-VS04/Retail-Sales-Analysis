Retail Sales Analysis

📌 Project Overview

This project focuses on analyzing a real-world retail sales dataset to identify sales trends, profitability, customer behavior, product performance, regional performance, and return patterns.

The project demonstrates an end-to-end data analysis workflow using Python.

🎯 Objectives

* Clean and preprocess retail sales data
* Handle missing values and duplicate records
* Analyze sales and profit performance
* Explore customer and product behavior
* Identify regional and category-wise trends
* Analyze discounts, returns, and delivery performance
* Create meaningful visualizations
* Generate business insights from the data

📊 Dataset

The dataset contains **50,000+ retail transaction records** with information related to:

* Orders
* Customers
* Products
* Categories
* Regions
* Sales channels
* Payment methods
* Discounts
* Sales
* Profit
* Delivery
* Customer ratings
* Returns

4. Run the notebook cells in order.
